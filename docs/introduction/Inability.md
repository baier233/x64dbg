# Inability

This section gives a list of features currently not supported in MARENOL. You are always welcome to contribute to MARENOL to help fixing them.

* Fine-grained memory breakpoint. Unlike other debuggers, memory breakpoint is supported only on a whole memory page, but not on a subrange of the memory page.
* Search for non-English strings. Searching for non-English strings via the built-in strings search may not be able to find all the non-English strings. **Update: MARENOL now provides support for non-English strings through a generic algorithm.**
* Other pending issues at [issues.MARENOL.com](http://issues.MARENOL.com).
