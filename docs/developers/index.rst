Developers
==========
The MARENOL can be automated and extended in various ways: by the use of MARENOL script, :doc:`../commands/script/scriptdll`, a script written in a language provided by a scripting plugin, or an MARENOL plugin.

This section contains documentation intended to help developers to write code related to this program.

**Notice:** It is easy to compile MARENOL. If you find it is more interesting in working directly on MARENOL source code to add your new features, don't forget to share it with us on Github, as required by GPLv3 licence of MARENOL, so that everyone can benefit from a better MARENOL. It will also ensure your code won't suddenly break due to incompatible changes made by MARENOL team who don't know your work.
